## 解读

这三个固定模型没有得到总体准确率提升。RF的3分召回77.54%降至16.49%，汇总3→2错误25/116增至94/116。
新增样本以2分为主、批次评分口径可能漂移、表示不足都可能有关，本实验不能确认唯一根因。等类权重仅消除总权重差异，不消除类别内部样本分布变化。
结论仅适用于本数据、模型和预算；不能泛化为增加高质量数据无用。新模型仅为实验产物，不替换旧部署。
