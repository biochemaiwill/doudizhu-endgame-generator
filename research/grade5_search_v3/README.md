# 继续寻找5分：第3轮记录

结论：本轮没有发现可按冻结rubric v0.1认证为5分的题目。

- 检索三人完整手牌来源、现有未认证悬赏题及公开实战牌例。
- 对3个源牌面尝试有限预算求解，均未完成三路整体认证（unknown，不代表输或赢）。
- 对源牌面生成固定随机种子2026110513的合法非终局前缀，筛选120次。
- 得到3个非平凡候选；复核全部前缀合法、三路根动作签名一致、不与旧100/新53/此前候选重复。
- 人工估计仅2—3分，未进入此次训练或正式数据集。所有估计仍未真人校准。

## 来源边界

百度2013最后牌例和小米2022-08-26给出20/17/17完整牌面，但全局搜索超出当前预算。
小米后文出现上家没有的10，因此不采用文章后续叙事，而只生成自己的合法前缀。
百度旧悬赏原文为20/17/16，合计53张；不猜缺牌。派生状态仅是依照这些已给牌生成的数学局面，不能声称完整真实原局。
同一个源牌面派生的状态共享family，不得跨训练/验证/测试。

## 产物与复现

source-inputs.json：逐来源输入、URL及说明。
search.json：完整筛选记录（包括排除和unknown）。
verified-candidates.json：三个三路验证的牌面与合法前缀。
review.json：保守人工难度估计与不标5的原因。
validation.json：三套完整根动作签名和前缀复核。
manifest.json：随机种子、软件环境、耗时与状态计数。

运行：
python3 research/grade5_search_v3/search.py
python3 research/grade5_search_v3/verify_candidates.py

本目录为隔离探索资料；不修改旧标签、不抬高分数、不改训练，不推断unknown状态胜负。
