# 方法调研与下一步假设（2026-11-05）

## 本次结论

本次8条支持样本实验未能学到已获验证的牌面推理表示。此次序数MLP、原始特征质心基线均未超过牌数岭回归。
这不能证明神经网络不适合，也不能证明牌数代表思维难度；更可能反映小样本、标签结构、领域表示不足的共同限制，尚须对照实验验证。

## 值得借鉴的原始来源

1. TabPFN：[Nature论文](https://www.nature.com/articles/s41586-024-08328-6)、[官方实现](https://github.com/PriorLabs/TabPFN)。
通过预训练先验解决小样本表格预测。适合作为现有86维特征的候选基线，而不是再次从零训练更大MLP。
本轮未下载权重、未运行，不能承诺在斗地主上提升；落地前固定版本、检查许可和下载大小。
2. TabICL：[官方项目](https://github.com/soda-inria/TabICL)、[官方文档](https://tabicl.readthedocs.io/en/latest/)。
基于上下文学习的表格基础模型，也是可比较的预训练基线。本轮未运行。
3. Prototypical Networks：[NeurIPS原论文](https://proceedings.neurips.cc/paper_files/paper/2017/hash/cb8da6767461f2812ae4290eac7cbc42-Abstract.html)。
借鉴“类别中心与距离”的思路。本轮只实现标准化原始特征的质心基线，没有元训练的嵌入空间，不能称作论文复现。
4. Set Transformer：[ICML原论文](https://proceedings.mlr.press/v97/lee19d.html)。
可用于手牌集合编码，但只对同一玩家手中牌的排列保持不变；牌点、地主/农民身份、行动顺序必须保留。
本轮未实现。
5. CORAL：[原论文](https://arxiv.org/abs/1901.07884)。
将有序分数转成多个阈值判断，并维持一致性。本项目MLP使用有序阈值思路，但参数化不同，不是原论文逐项复现。
有序损失不能凭空补足5分样本。

## 优先顺序

- 先补充不同来源/解法机制的高分题及普通玩家解题记录，冻结新的题族隔离评测集；不要不断对现有15题调参。
- 在同一冻结协议下比较TabPFN/TabICL与简单基线；“需要下载多少权重、是否CPU可行”在选择具体版本时验证。
- 中期候选：角色感知的手牌编码器，在可大量生成且可验证的胜负/合法出法任务上预训练，再用少量难度标签微调三头序数预测及成对排序。
这是待检验方案：胜负推理能力不等于人类难度判断，仍需玩家数据校准。
- 最终训练生成器前，用独立题族测排序、高分精度、置信度和分布外表现，并检查生成器是否仅增加牌数来刷分。
自回归采样为离散过程，不能默认把评分器输出直接当可微loss反传；可研究策略梯度或先筛选再微调，但此轮未实施。

5分仍无经过验证并符合当前口径的样本。不得把4分改名为5分凑平衡；当前模型仅支持1—4分。
