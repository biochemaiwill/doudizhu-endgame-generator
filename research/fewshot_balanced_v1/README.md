选中牌数岭回归alpha=1：测试总体MAE 0.624 ± 0.122，测试宏MAE 0.567 ± 0.142（5次抽样均值±样本标准差）。
其中4分测试题的平均绝对误差0.702。神经网络和原始特征质心均未胜过牌数基线。
这意味着当前实验不足以证明学到了推理难度，不能接入生成器作为可靠奖励。

上一轮70题模型测试总体MAE为0.540，4分题误差为1.276。
本轮高分误差较小，但总体误差较大。训练规模、采样分布和选模指标同时改变，不能将差异单独归因于均衡采样。
两轮均使用同一已曝光开发测试集，不是新的独立验证。

## 局限

- 每次4分训练样本固定为同一题族的两道，测试集只有一道4分题。5次重复不等于5次独立高分验证。
- 样本标准差仅反映训练支持集抽样变化，不是泛化误差的置信区间。
- 均衡按总分进行，两个子维度不保证均衡；普通玩家标注与5分题均缺失。
- 新增高分同族变体未混入本轮，原数据及原实验结果未修改。
- 默认导出seed101单次8题模型；方法按5次平均验证结果选出，未将5次模型合成后冒充2-shot。
- 仍只支持1—4分，明确禁止声称5分预测已验证。
