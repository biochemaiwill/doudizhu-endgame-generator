# 100道三人明牌残局：LLM试标 v0.1

日期：2026-11-05。状态：数据先导批次完成，未训练评分器；不是人类难度金标准。

## 结果
- 100道互异状态，和原6道锚点的规范化局面无重合。
- 来源：MasterMind公开训练集50道、公开人工题目/题解8道、随机对照30道、针对性结构筛选12道。
- 总分分布：1分42道，2分39道，3分15道，4分4道，5分0道。不为了类别平衡抬分。
- 对象：经常打斗地主的普通玩家；保留总分、推理深度、出法隐蔽性和逐题理由。
- 标签由本次对话助手单次人工式审阅生成，评分前查看了求解证据；没有独立LLM投票、盲评或真人校准。
- 100题全部重新核查物理牌约束和每个合法首着的胜负；优化求解器、关闭规范化版本、独立动作枚举参考搜索一致。
- 验证只针对固定牌型规则；共用牌点定义，两份程序一致不是所有玩法下正确的形式证明。

## 阅读和使用
- dataset.jsonl：机器可读数据；input仅含局面，target为三个序数等级，reason为简短依据。
- selection.json：逐首着胜负、示范线、错误首着的示范反驳线。
- validation.json：100题交叉检查、来源数量、分数分布和dataset SHA256。
- annotation-inputs.json：本次助手实际给出的逐题评分，区别于程序筛选条件。
- rubric.md：沿用已批准的六题评分口径。
- 原6题仍在 ../pilot-v1，作为口径锚点独立保留。

分数没有按牌数、节点数、唯一胜着比例套公式。结构筛选只用于找候选，最终评分经过逐题阅读。没有强行补出5分。
示范线仅是双方维持各自胜负结果的一条走法；必败方不一定选择对人最难的抵抗方式，不能把示范线长度解释为客观人类推理步数。

## 来源核查与局限
MasterMind通过官方datasets-server API分24个页面抽查2400行，保留了去重后的325个不超过20张的候选及其原始sentence。因为这里只取了小样本，不代表全量质量/分布；部分上游字段与数据卡描述不一致，按实际sentence/answer结构解析。没有下载98MB的完整训练文件。
卡牌编码按DouZero官方game.py验证：17=2，20=小王，30=大王；其get_last_two_moves采用最近动作在前。解析器同时核对上游给出的合法动作集合。对最近动作顺序的解释仍依赖这份上游接口约定；它没有独立完整对局历史可作最终核查。
https://raw.githubusercontent.com/kwai/DouZero/main/douzero/env/game.py

MasterMind的动作答案来自代理预测，本批不把它当精确答案，而是重新求解。原始对局ID未提供，因此不宣称已经得到按对局隔离的独立训练/测试集。暂未切分数据，也不将这100题直接用于优化生成器。

公开题目只摘录局面事实，保留作者、URL与题号，分析和评分为本次新写：
- 33IQ：smok，题579558、579557；katy Clarkson，题507272。来自可公开阅读的主题列表；未绕过付费/登录查看答案。
  https://www.33iq.com/topic/4961/
  https://www.33iq.com/topic/574/7/
- 头头来了：欢乐斗地主实战精彩残局分析。记录直接局面和文中明确后续状态；5-follow按地主已经打出K还原，因此地主手中去掉一张K。
  https://www.gamersky.com/handbook/201411/487845.shtml
- 同一文章的多个局面有关联，应按family成组，不能当作独立测试样本。
- source-verification与public-ordered-verification保留失败/未知记录；后者仅用等价的动作排序加速独立参考搜索，未修改游戏规则。
- gamersky-2-follow的公开牌面存在物理张数冲突，已排除。几个公开题在请求行动方并非必胜，已排除；预算超限的题保留unknown，未打难度标签。
- RefGPT展示样例未通过地主必胜要求，不作为正确解答集使用。
- 未核定公开网页题目批量再分发许可；本批只有局面事实、出处和自行求解结果，不复制原文解析，不给第三方素材另加开源许可证。

合成部分共有两轮固定seed采样，原始台账不删除：
- candidates.jsonl/run.json：342次尝试，180验证通过，124当前行动方不能保证赢，25超时，13仅一合法动作。
- hard-candidates.jsonl/hard-run.json：结构筛选只作为找题线索，不是难度标签；保留全部失败、超时和被筛除候选。
- 合成局面为合法剩余手牌加可选合法动作前缀，不宣称都能从常规开局历史到达。
- 随机候选依旧偏简单；公开人工题使本批补到了4分结构，但高难度样本仍不足。

## 复现
在服务器仓库根目录运行：
    python3 research/pilot100/tests.py
    python3 research/pilot100/select.py
    python3 research/pilot100/finalize.py

这些命令使用已保留候选，不会下载模型、不调用付费API、不启动训练。finalize会重算100题验证并按冻结人工式标签输出数据。
重新联网采样不是精确复现原网页快照；复现此批以已保存的局面文本、来源、候选文件和散列为准。
共11项合同/解析测试；100题逐首着重新验证。原版完整参考搜索运行过一部分较大公开题并超时，记录已保留；排序参考版本成功者才可纳入本批。

## 下一步边界
先抽查4分题及相邻等级，必要时修订口径并保留旧版本。之后补充复杂公开题及少量真人数据。
这100题可用于研究评分器输入、序数建模和排序基线，不能证明评分器已泛化。没有单独训练集外评价、没有真人校准前，不把模型高分直接当作生成器已进步。
本批不训练评分器，不修改用户另一台电脑上的自回归模型。
