## 数量增加不等于高分覆盖改善

新样本主要为2分，4分仍14题且题族有限。
本批未因追求300数量目标强行增加4/5分，也未把冲突标签静默作为训练真值。
模型对照显示增加这批数据反而降低旧验证题表现，见MODEL_RESULTS.md；不能宣称扩容有效。
