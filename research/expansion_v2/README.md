# 第二批扩充：三人明牌残局与等牌数对照

本批保持原 `rubric v0.1`：面向经常打斗地主的普通玩家，记录总分、推理深度、出法隐蔽性和简短依据。
求解器只证明规则下的胜负；难度依旧是助手试标，尚无真人校准。

本批正式收录 **53道**：1分15、2分7、3分27、4分4、5分0；包含15组严格等三家牌数对照。

## 数据来源与收录

- 固定种子独立生成并筛选剩余手牌，保存全部筛选日志（search-ledger.jsonl.gz，无损压缩）。共得到100个三路认证候选，对35个完成深入试标，其余65个保持未标注。
- 新公开来源：新浪2012文章的合法后继局面、53shop 2023的完整三人牌面。
- 重新认证此前未解决的33IQ 507273；它是此前发现的来源，本轮新获得完整证据，不声称本轮新发现。
- 另构造15道简单对照：行动人整手可以一次出完，三家的剩余牌数和行动状态与对应较难题完全一致。它们是人工构造的诊断对照，不是自然对局样本；也没有保持相同牌点总集合。

正式JSONL：[dataset.jsonl](dataset.jsonl)。完整牌面：[SAMPLES.md](SAMPLES.md)。配对：[pairs.json](pairs.json)。
逐动作证据：[evidence.json](evidence.json)。筛选池保留在verified-pool.json，35个深入试标见labels_agent.json。

## 验证与局限

每条收录数据从序列化输入重新恢复，在冻结供应商规则下对全部合法根动作做三路核对：
优化求解器、关闭点数压缩的求解器、独立枚举参考求解器。全部一致且行动方存在必胜策略。
与原100题、最初6个锚点及上轮候选进行规范化键去重。
这不等于证明所有局面都有完整真实对局历史，也不等于覆盖所有平台规则。

新公开资料的原答案未直接采信：
- 小米文章指定局面：行动方实际上无必胜首着，排除。
- 新浪原始地主局面：地主必败；收录的是明确“地主已经出Q后”的农民决策。
- 53shop把答案写成“一对9”，但牌面只有一张9；不补牌，重新求解得到单9。
- 33IQ题仅因三路认证完成而从未知转为收录，不能用搜索耗时给5分。

没有获得足以高于旧4分锚点的5分证据，本批仍无5分。
3/4分理由来自具体出法、反例和关键分支，不由胜着数量、搜索节点或示范线长度自动换算。
100个候选都通过胜负筛选，但只有35个深入试标；不得将100称作100条新增难度标签。

## 划分和使用

旧数据、旧train/val/test与旧评分器均不改动，本批尚未进入训练。
配对双方共享family，必须整体进入同一划分。同题变体也不得跨划分。
独立采样的合成题仍共享生成流程，不能据此宣称已覆盖真实玩家分布。
15个一手出完对照是“模型不能只用牌数”的基础诊断，不能替代更细粒度的自然配对或最终玩家评测。

## 复现

仅服务器CPU、标准库，未下载大型模型，未在用户电脑落盘数据。
运行前请使用隔离副本/新输出目录，脚本拒绝覆盖现有数据。

- 合并及逐条新认证：python3 research/expansion_v2/assemble.py
- 产物测试：python3 research/expansion_v2/tests.py
