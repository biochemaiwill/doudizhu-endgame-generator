# 牌面评分器 v1 先导训练 Implementation Plan

> For agentic workers: Use superpowers:executing-plans. 用户已批准“先训练看看”、牌面直接推理、分层划分；本计划落实批准范围，不触及生成器训练。

**Goal:** 用冻结100题训练并比较轻量牌面评分器，输出三个序数分数和可复核测试结果。
**Architecture:** 仅从牌面提取计数和轮次特征。以常数、牌数线性、全牌面岭回归及小型序数MLP作比较；训练CPU单线程，验证集选参数/模型，测试集只在选择冻结后评估。
**Tech Stack:** 服务器已有research环境中的NumPy/scikit-learn/PyTorch/SciPy，不安装依赖。
**Spec:** research/pilot100/rubric.md 与2026-11-05用户批准。

## Global Constraints
- pilot100/dataset.jsonl保持原样，SHA256=85b3d83ca0ed203801161299c83178f858b8e0d3e3a6a288341ca759ada0b59c。
- 推理输入只含三家手牌/轮次/上一手/过牌数，不含来源、答案或求解器特征。
- 不新增本地文件，不运行GPU，不修改其他项目，不训练生成器。
- 三人顺序不交换；手牌内部排列不影响编码。
- 5分无样本，不宣称可识别5分；推理返回不支持5分的状态。
- 50道MasterMind来源无对局号，全部留train；同一公开文章家族不拆分。
- 70/15/15分层目标：overall 1/2/3/4分别train=30/27/11/2，val=test=6/6/2/1。
- 这是来源受限的小样本开发实验，标签作者已见全部题，不是独立人类测试集。
- 高分数据收集另行并行，不回填本次冻结划分。

## Review Focus
1. 任一答案/来源进入特征属于泄漏。
2. 标准化和模型拟合仅用train，test不得选参。
3. 家族分组与分层冲突不得静默随机拆分。
4. 无5分标签不得伪造5分性能。
5. 异常输入、模型序列化与推理重载一致性。
