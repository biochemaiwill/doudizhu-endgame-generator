# 100题三人残局试标 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 扩展100道不同三人明牌必胜残局的可复核LLM试标数据。
**Architecture:** 固定随机种子合成小残局；保留全部候选和失败；双实现验证根节点全部合法出法。助手逐题审阅，标注总分/深度/隐蔽性和依据。六题示例单独作为口径锚点。
**Tech Stack:** 服务器Python标准库、已固定版本的MIT求解器。CPU单进程为主。
**Spec:** research/pilot-v1/README.md及用户2026-11-05对六题口径和扩展方案的批准。

## Global Constraints
- 不修改原六题、上游代码、现有生成模型或生产项目。
- 本地不创建项目文件；不安装依赖、不用GPU、不调付费模型API。
- 总分为估计的普通玩家难度；不伪装真人标签，不按数量凑高分。
- 100题是先导语料，不直接声称足够训练可靠评分器。
- 不得把超时、求解失败、未知当成必胜或必败。
- 批次限单核、总运行30分钟以内；所有尝试有台账。
- 分数由助手审阅牌面及证据后给出，程序只做验证、选择和汇总。
- 固定100题之外保留候选、拒绝和超时，不删除科研证据。

## Review Focus
- 农民同队不应被误做三方竞争。
- 跨人手牌重数、带牌规则及在途过牌状态。
- 等价点数局面泄漏与原6题污染。
- 搜索预算造成的筛选偏差。
- 唯一胜着或牌数成为难度公式的风险。
